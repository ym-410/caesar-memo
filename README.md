# Caesar Memo

Caesar Memoはシーザー暗号を使って本文を暗号化して保存するCLIメモ帳アプリです。

## 機能

- メモの作成、表示、更新、削除
- タイトルの類似検索
- 検索結果のスコア順ソート
- メモ本文の暗号化・復号化
- パスワードからシフト数を生成
- ひらがな、カタカナ、漢字の暗号化に対応
- `notes.json` への保存

## 使用技術

- Python 3.12
- uv
- Python 標準ライブラリのみ

## セットアップ

このプロジェクトは Python 3.12 と uv を使って実行します。
初回はプロジェクトルートで次のコマンドを実行してください。

```powershell
uv sync
```

`uv sync` によって仮想環境 `.venv` が作成され、`caesar-memo` コマンドで起動できるようになります。

サンプルデータを使う場合は、`notes.example.json` を `notes.json` にコピーしてください。

```powershell
Copy-Item notes.example.json notes.json
```

`notes.json` がない場合はメモを追加したときに自動で作成されます。  

## 起動方法

セットアップ後、プロジェクトルートで次のコマンドを実行します。

```powershell
python main.py
```

uv のコマンドとして起動する場合は、次のコマンドでも実行できます。

```powershell
uv run caesar-memo
```

起動すると CLI メニューが表示されます。

```bash
=== Caesar Memo ===
1. メモを追加する
2. メモ一覧を見る
3. メモを確認する
4. メモを更新する
5. メモを削除する
6. タイトルから検索する
0. 終了
選択してください:
```

`src\caesar_memo\main.py` を直接実行する方法では、相対インポートの関係で起動できません。
必ずプロジェクトルートの `main.py` または `uv run caesar-memo` で起動してください。

## 使い方

メニュー番号を入力して操作します。

### メモを追加する

```bash
選択してください: 1
タイトル: Hello
本文: Hello Caesar
パスワード：pass123
メモを保存しました。タイトル：Hello
```

本文は、パスワードから生成したシフト数でシーザー暗号化して `notes.json` に保存されます。

### メモ一覧を見る

```bash
選択してください: 2

メモ一覧:
==================
1.Hello
```

### メモを確認する

```bash
選択してください: 3
確認するメモのID:1
パスワード：pass123

==================
タイトル: Hello
------------------
本文:
Hello Caesar
==================
```

メモを追加したときと同じパスワードを入力すると、本文を復号して確認できます。

### メモを更新する

```bash
選択してください: 4
更新するメモのID:1
変更後のタイトル: Updated
本文を入力してください: Updated Caesar
パスワード：pass123
ノートを更新しました
```


### メモを削除する

```bash
選択してください: 5
削除するメモのID:1
メモ(ID:1)が削除されました。
```

存在しないIDを指定した場合は、エラーメッセージを表示します。

### メモを検索する

```bash
選択してください: 6
検索キーワード: python

検索結果
id: 1, title:Hello Python 類似度: 45.45%
```

検索はタイトルを対象に行います。検索キーワードとタイトルを 2-gram に分割して類似度を計算し、類似度が一定以上のメモを結果として表示します。

検索結果は、マージソートを使って類似度の高い順に並び替えます。

## 構成

```text
src/caesar_memo/
├─ main.py           # CLIメニューと入出力
├─ crypto.py         # シーザー暗号
├─ password_shift.py # パスワードからシフト数を生成
├─ storage.py        # JSON保存とCRUD
├─ search.py         # 2-gram類似検索
└─ sorter.py         # マージソート
```

## 保存先

メモはプロジェクトルートの `notes.json` に保存されます。

```text
caesar-memo/
├─ main.py
├─ notes.json
└─ src/
   └─ caesar_memo/
      ├─ main.py
      └─ storage.py
```

`notes.json` はローカルデータのため、Git 管理対象外です。初期状態のサンプルとして `notes.example.json` を置いています。  
`notes.example.json` のサンプル本文は、パスワード `pass123` で復号できます。

保存されるメモには、作成日時を表す `created_at` と、更新日時を表す `updated_at` が含まれます。

```json
{
  "id": 1,
  "title": "Hello",
  "body": "Yvccf Trvjri",
  "created_at": "2026-07-03T18:30:00+09:00",
  "updated_at": "2026-07-03T18:30:00+09:00"
}
```

## 仕組み

1. 入力されたパスワードの各文字を `ord()` で数値に変換する
2. 変換した数値を合計する
3. 合計値を 26 で割った余りから、シーザー暗号のシフト数を決定する
4. メモ本文の英字、ひらがな、カタカナ、漢字をシーザー暗号で変換する
5. タイトル、暗号化済み本文、作成日時、更新日時を `notes.json` に保存する

ひらがな、カタカナ、漢字は、それぞれの Unicode 範囲内で循環シフトします。数字と記号はそのまま保持します。  
メモを更新した場合、`created_at` は変更せず、`updated_at` のみ更新します。  
復号時は逆の流れで処理します。

## 注意

このアプリにおける暗号化は講義内で取り扱いのあったシーザー暗号を使用しており、実運用でのセキュリティは十分とは言えません。
パスワードが誤っていても、シーザー暗号は何らかの文字列を返します。このアプリにはパスワードの正しさを検証する仕組みはありません。

`notes.json` が存在しない、またはJSONとして読み取れない場合は、空のメモ一覧として扱います。読み取れないファイルを上書きしないよう、利用前にバックアップを作成してください。
