# Caesar Memo

Caesar Memo は、シーザー暗号と Base64 を使って本文を暗号化して保存する CLI メモ帳アプリです。
パスワードから SHA-256 ハッシュを作成し、その値をもとにシーザー暗号のシフト数を決定します。

## 機能

- メモの追加
- 保存済みメモの一覧表示
- 保存済みメモの復号表示
- 保存済みメモの更新
- 保存済みメモの削除
- メモ本文の暗号化
- 暗号文の Base64 エンコード
- Base64 文字列の復号化
- パスワードからシフト数を生成
- 英字の大文字・小文字に対応
- 日本語、数字、記号はそのまま保持
- CLI メニューによる操作
- `notes.json` への保存
- 作成日時・更新日時の保存

## 使用技術

- Python 3.12
- uv
- Python 標準ライブラリのみ

## 実行方法

```powershell
uv run python src\caesar_memo\main.py
```

または、仮想環境を有効化して実行します。

```powershell
.\.venv\Scripts\python.exe src\caesar_memo\main.py
```

## 使い方

起動すると、以下のメニューが表示されます。

```bash
=== Caesar Memo ===
1. メモを追加する
2. メモ一覧を見る
3. メモを確認する
4. メモを更新する
5. メモを削除する
0. 終了
選択してください:
```

### メモを追加する

```bash
選択してください: 1
タイトル: Hello
本文: Hello Caesar
パスワード：pass123
メモを保存しました。タイトル：Hello
```

本文は、パスワードから生成したシフト数でシーザー暗号化したあと、Base64 文字列に変換して `notes.json` に保存されます。

### メモ一覧を見る

```bash
選択してください: 2

メモ一覧:
==================
1.Hello
```

### メモを確認する

```bash
選択してください: 3
確認するメモのID:1
パスワード：pass123

==================
タイトル: Hello
------------------
本文:
Hello Caesar
==================
```

メモを追加したときと同じパスワードを入力すると、本文を復号して確認できます。

### メモを更新する

```bash
選択してください: 4
更新するメモのID:1
変更後のタイトル: Updated
本文を入力してくださいUpdated Caesar
パスワード：pass123
ノートを更新しました
```

更新時も、本文はパスワードから生成したシフト数で暗号化し、Base64 文字列に変換して保存されます。

### メモを削除する

```bash
選択してください: 5
削除するメモのID:1
メモ(ID:1)が削除されました。
```

存在しないIDを指定した場合は、エラーメッセージを表示します。

## 保存先

メモはプロジェクトルートの `notes.json` に保存されます。

```text
caesar-memo/
├─ notes.json
└─ src/
   └─ caesar_memo/
      ├─ main.py
      └─ storage.py
```

`notes.json` はローカルデータのため、Git 管理対象外です。初期状態のサンプルとして `notes.example.json` を置いています。

保存されるメモには、作成日時を表す `created_at` と、更新日時を表す `updated_at` が含まれます。

```json
{
  "id": 1,
  "title": "Hello",
  "body": "S2hvb3IgRmRodmR1",
  "created_at": "2026-07-03T18:30:00+09:00",
  "updated_at": "2026-07-03T18:30:00+09:00"
}
```

## 仕組み

1. 入力されたパスワードを SHA-256 でハッシュ化する
2. ハッシュ値を数値に変換する
3. 数値からシーザー暗号のシフト数を決定する
4. メモ本文の英字をシーザー暗号で変換する
5. 変換後の文字列を UTF-8 にして Base64 エンコードする
6. タイトル、暗号化済み本文、作成日時、更新日時を `notes.json` に保存する

メモを更新した場合、`created_at` は変更せず、`updated_at` のみ更新します。

復号時は逆の流れで処理します。

## 注意

このアプリで使用しているシーザー暗号は、学習用の古典暗号です。実用的なセキュリティ用途には使用しないでください。
また、Base64 は暗号化ではなく、文字列を扱いやすくするためのエンコード方式です。
