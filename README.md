# Caesar Memo

Caesar Memo は、シーザー暗号と Base64 を使って文字列を暗号化・復号化する CLIメモ帳アプリです。  
パスワードから SHA-256 ハッシュを作成し、その値をもとにシーザー暗号のシフト数を決定します。

## 機能

- 文字列の暗号化
- 暗号文の Base64 エンコード
- Base64 文字列の復号化
- パスワードからシフト数を生成
- 英字の大文字・小文字に対応
- 日本語、数字、記号はそのまま保持
- CLI メニューによる操作

## 使用技術

- Python 3.12
- uv
- Python 標準ライブラリのみ

## 実行方法

```powershell
uv run python src\caesar_memo\main.py
```

または、仮想環境を有効化して実行します。

```powershell
.\.venv\Scripts\python.exe src\caesar_memo\main.py
```

## 使い方

起動すると、以下のメニューが表示されます。

```bash
=== Caesar Memo ===
1. 暗号化する
2. 復号化する
0. 終了
選択してください:
```

### 暗号化

```bash
選択してください: 1
暗号化する文字列: Hello Caesar
パスワード：pass123

暗号化結果:
SmdubnEgRWNndWN0
```

### 復号化

```bash
選択してください: 2
復号化する文字列: SmdubnEgRWNndWN0
パスワード：pass123

復号結果:
Hello Caesar
```

暗号化時と同じパスワードを入力すると、元の文字列に復号できます。

## 仕組み

1. 入力されたパスワードを SHA-256 でハッシュ化する
2. ハッシュ値を数値に変換する
3. 数値からシーザー暗号のシフト数を決定する
4. 入力文字列の英字をシーザー暗号で変換する
5. 変換後の文字列を UTF-8 にして Base64 エンコードする

復号時は逆の流れで処理します。

## 注意

このアプリで使用しているシーザー暗号は、学習用の古典暗号です。実用的なセキュリティ用途には使用しないでください。
また、Base64 は暗号化ではなく、文字列を扱いやすくするためのエンコード方式です。
