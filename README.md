# Caesar Memo

Caesar Memo は、シーザー暗号と Base64 を使って本文を暗号化して保存する CLI メモ帳アプリです。
パスワードから SHA-256 ハッシュを作成し、その値をもとにシーザー暗号のシフト数を決定します。

## 機能

- メモの追加
- 保存済みメモの一覧表示
- 保存済みメモの復号表示
- 保存済みメモの更新
- 保存済みメモの削除
- タイトルの類似検索
- 検索結果の類似度表示
- 検索結果のスコア順ソート
- メモ本文の暗号化
- 暗号文の Base64 エンコード
- Base64 文字列の復号化
- パスワードからシフト数を生成
- 英字の大文字・小文字に対応
- ひらがな、カタカナ、漢字の暗号化に対応
- 数字、記号はそのまま保持
- CLI メニューによる操作
- `notes.json` への保存
- 作成日時・更新日時の保存

## 使用技術

- Python 3.12
- uv
- FastAPI
- Uvicorn

## 実行方法

### CLI

```powershell
uv run python src\caesar_memo\main.py
```

または、仮想環境を有効化して実行します。

```powershell
.\.venv\Scripts\python.exe src\caesar_memo\main.py
```

### HTTP API

FastAPI を使って HTTP API サーバーを起動できます。

```powershell
uv run uvicorn src.caesar_memo.api:app --reload
```

起動後、以下のURLにアクセスできます。

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/ui
http://127.0.0.1:8000/notes
http://127.0.0.1:8000/docs
```

VS Code で `fastapi` の import エラーが表示される場合は、このプロジェクトの仮想環境を Python インタプリタとして選択してください。

```text
.\.venv\Scripts\python.exe
```

## 使い方

### Web UI

API サーバーを起動したあと、以下のURLを開くとブラウザからメモを操作できます。

```text
http://127.0.0.1:8000/ui
```

Web UI では、メモの作成、一覧表示、タイトル検索、復号、更新、削除ができます。

### CLI

起動すると、以下のメニューが表示されます。

```bash
=== Caesar Memo ===
1. メモを追加する
2. メモ一覧を見る
3. メモを確認する
4. メモを更新する
5. メモを削除する
6. タイトルから検索する
0. 終了
選択してください:
```

### メモを追加する

```bash
選択してください: 1
タイトル: Hello
本文: Hello Caesar
パスワード：pass123
メモを保存しました。タイトル：Hello
```

本文は、パスワードから生成したシフト数でシーザー暗号化したあと、Base64 文字列に変換して `notes.json` に保存されます。

### メモ一覧を見る

```bash
選択してください: 2

メモ一覧:
==================
1.Hello
```

### メモを確認する

```bash
選択してください: 3
確認するメモのID:1
パスワード：pass123

==================
タイトル: Hello
------------------
本文:
Hello Caesar
==================
```

メモを追加したときと同じパスワードを入力すると、本文を復号して確認できます。

### メモを更新する

```bash
選択してください: 4
更新するメモのID:1
変更後のタイトル: Updated
本文を入力してくださいUpdated Caesar
パスワード：pass123
ノートを更新しました
```

更新時も、本文はパスワードから生成したシフト数で暗号化し、Base64 文字列に変換して保存されます。

### メモを削除する

```bash
選択してください: 5
削除するメモのID:1
メモ(ID:1)が削除されました。
```

存在しないIDを指定した場合は、エラーメッセージを表示します。

### メモを検索する

```bash
選択してください: 6
検索キーワード: python

検索結果
id: 1, title:Hello Python 類似度: 45.45%
```

検索はタイトルを対象に行います。検索キーワードとタイトルを 2-gram に分割して類似度を計算し、類似度が一定以上のメモを結果として表示します。

検索結果は、マージソートを使って類似度の高い順に並び替えます。

## HTTP API

以下のエンドポイントを実装しています。

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/` | API の動作確認メッセージを返す |
| GET | `/notes` | 保存済みメモ一覧を JSON で返す |
| GET | `/notes/search` | タイトルからメモを検索する |
| POST | `/notes` | メモを作成する |
| POST | `/notes/{note_id}/decrypt` | 指定したメモを復号して返す |
| PUT | `/notes/{note_id}` | 指定したメモを更新する |
| DELETE | `/notes/{note_id}` | 指定したメモを削除する |

### メモ作成

```text
POST /notes
```

リクエスト例:

```json
{
  "title": "Hello",
  "body": "Hello Caesar",
  "password": "pass123"
}
```

レスポンス例:

```json
{
  "id": 1,
  "title": "Hello",
  "created_at": "2026-07-03T18:30:00+09:00"
}
```

### メモ復号

```text
POST /notes/1/decrypt
```

リクエスト例:

```json
{
  "password": "pass123"
}
```

レスポンス例:

```json
{
  "id": 1,
  "title": "Hello",
  "body": "Hello Caesar",
  "created_at": "2026-07-03T18:30:00+09:00",
  "updated_at": "2026-07-03T18:30:00+09:00"

```

### メモ更新

```text
PUT /notes/1
```

リクエスト例:

```json
{
  "title": "Updated",
  "body": "Updated Caesar",
  "password": "pass123"
}
```

レスポンス例:

```json
{
  "id": 1,
  "title": "Updated",
  "updated_at": "2026-07-03T19:00:00+09:00"
```

### メモ削除

```text

```

```json

```

### メモ検索

```text

```

検索はタイトルを対象に行います。検索結果は類似度の高い順に並びます。

レスポンス例:

```json

    "id": 1,
    "title": "Python学習",
    "score": 0.45,
    "updated_at": "2026-07-03T18:30:00+09:00"

```

## 保存先

メモはプロジェクトルートの `notes.json` に保存されます。

```text
caesar-memo/
├─ notes.json
└─ src/
   └─ caesar_memo/
      ├─ main.py
      └─ storage.py
```

`notes.json` はローカルデータのため、Git 管理対象外です。初期状態のサンプルとして `notes.example.json` を置いています。

保存されるメモには、作成日時を表す `created_at` と、更新日時を表す `updated_at` が含まれます。

```json
{
  "id": 1,
  "title": "Hello",
  "body": "S2hvb3IgRmRodmR1",
  "created_at": "2026-07-03T18:30:00+09:00",
  "updated_at": "2026-07-03T18:30:00+09:00"
}
```

## 仕組み

1. 入力されたパスワードを SHA-256 でハッシュ化する
2. ハッシュ値を数値に変換する
3. 数値からシーザー暗号のシフト数を決定する
4. メモ本文の英字、ひらがな、カタカナ、漢字をシーザー暗号で変換する
5. 変換後の文字列を UTF-8 にして Base64 エンコードする
6. タイトル、暗号化済み本文、作成日時、更新日時を `notes.json` に保存する

ひらがな、カタカナ、漢字は、それぞれの Unicode 範囲内で循環シフトします。数字と記号はそのまま保持します。

メモを更新した場合、`created_at` は変更せず、`updated_at` のみ更新します。

復号時は逆の流れで処理します。

検索時は本文を復号せず、タイトルのみを対象にします。

## 注意

このアプリで使用しているシーザー暗号は、学習用の古典暗号です。実用的なセキュリティ用途には使用しないでください。
また、Base64 は暗号化ではなく、文字列を扱いやすくするためのエンコード方式です。
